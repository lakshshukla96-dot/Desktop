About this project

A front-end project built with HTML, CSS and JavaScript only.

Why Explore Bharat

India is large enough that most travellers see only a small part of it. Explore Bharat is a digital travel guide that puts destinations, festivals and food for every region in one place.

The aim is to inspire domestic and international tourism through a clear, responsive interface that works on a phone as well as a desktop.

What it uses

  1. HTML5 for page structure and content.
  2. CSS3 for Flexbox and Grid layouts, media queries and hover effects.
  3. JavaScript for the slider, live search, filtering, modal and form validation.
